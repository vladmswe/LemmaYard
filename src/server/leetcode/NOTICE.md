# LeetCode catalog: third-party notice

`catalog.json` in this folder is generated by `pnpm leetcode:catalog` from the
public dataset **zerotrac/leetcode_problem_rating**
(https://github.com/zerotrac/leetcode_problem_rating), MIT licence, copyright
(c) 2021 Shuxin Chen. The full licence text is below.

Dataset commit: `df2f5b9e11db26574da3956271d98a551bff7ba4`
Retrieved: 2026-10-18

What the catalog holds: facts about LeetCode contest problems (problem number,
slug, title, contest and position) and the dataset's community contest
ratings. It never holds problem statements, examples, constraints, hints,
editorials, solutions, tests or premium content. LemmaYard never requests
anything from leetcode.com: rooms only link to public problem pages, which
open in the user's own browser.

`overlay.json` holds LemmaYard's own labels (topic tags, difficulty
overrides, premium/exclude flags, extra problems). Values marked
`"estimated"` there are estimates and are labelled as such in the app.

LeetCode is a trademark of LeetCode LLC. LemmaYard is not affiliated with or
endorsed by LeetCode.

## Refreshing the catalog (maintainer)

1. Find the dataset's latest commit and download `data.json` at that commit
   (anonymous HTTPS, no account needed; nothing is fetched from leetcode.com):

   ```bash
   git ls-remote https://github.com/zerotrac/leetcode_problem_rating refs/heads/main
   curl -fL -o /tmp/data.json \
     https://raw.githubusercontent.com/zerotrac/leetcode_problem_rating/<sha>/data.json
   ```

2. Regenerate (offline; writes `catalog.json` and the commit/date above):

   ```bash
   pnpm leetcode:catalog --input /tmp/data.json --commit <sha>
   ```

3. Review `git diff --stat src/server/leetcode/`, run `pnpm test`, commit both
   files. `overlay.json` is never changed by the script.
